Reconciliation and safety

These settings apply globally. They are saved and validated with the complete configuration using the actions below Continuous mappings.

Pauses a bulk plan before any writes when configured removal limits are exceeded.
Advanced safety thresholds

Adjust the limits that pause bulk removal plans. The defaults are intended for ordinary libraries.

Continuous mappings

Additive mappings preserve manual target state and only add supported targets. Authoritative mappings make the configured sources decisive and may remove unsupported targets.

Save configuration validates with the server and saves immediately when no removals are needed. Preview changes does not save. After a save is accepted, metadata changes settle in the background.

Run once

Save reusable mapping-shaped groups that only run when explicitly previewed and confirmed. Exclusions retain an item's observed target state for one preview and are never saved.

Full Reconcile

Queue a background whole-library repair. A plan that exceeds destructive limits pauses before writes.

Operations and diagnostics

Add new collection

Creation takes effect immediately in Jellyfin and is not rolled back if you cancel or a later save fails. After creation, the new collection is selected in the picker you opened this from. The collection starts locked so metadata providers cannot replace its explicit name; unlock it later in Jellyfin if you prefer provider-managed collection metadata.

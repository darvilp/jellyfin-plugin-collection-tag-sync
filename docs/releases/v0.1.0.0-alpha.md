# Collection Tag Sync 0.1.0.0 alpha

This is the first public, installable alpha of Collection Tag Sync. Back up the
Jellyfin configuration and data directories before installing it, and review
every destructive preview before confirmation.

## Compatibility

- Jellyfin server: 10.11.11
- Plugin target ABI: 10.11.11.0
- Plugin runtime: .NET 9 (`net9.0`)
- Validated environment: Jellyfin's 10.11.11 Linux container under WSL 2
- Native Windows Jellyfin and older server releases are not claimed compatible

## Included behavior

- Explicit Tag ↔ Collection target groups over direct Movie and Series metadata
- Additive and Authoritative policies with OR aggregation and multi-hop DAG
  propagation
- Serialized near-real-time processing plus manual, startup, and scheduled Full
  Reconcile
- Destructive circuit-breaker previews and administrator-bound confirmation
- Previewed run-once operations with direct-target exclusions
- GUID-backed collection selection and a distinct, independently persistent Add
  New collection action
- Embedded administrator UI backed by server-side validation and authorization

## Installation

Add this third-party repository in the Jellyfin plugin dashboard:

```text
https://raw.githubusercontent.com/darvilp/jellyfin-plugin-collection-tag-sync/manifest/manifest.json
```

Install Collection Tag Sync 0.1.0.0 from the catalog and restart Jellyfin when
prompted.

## Configuration and upgrade notes

- Configuration schema version 1 is present from the first public package.
- This is the first release, so there is no prior public package from which to
  prove a cross-version migration. The next release must add and run an
  upgrade/configuration-retention smoke test against this package.
- Back up the Jellyfin configuration and data directories before every alpha
  upgrade.
- Collection creation is immediate and remains in Jellyfin if its surrounding
  configuration or run-once workflow is canceled or rejected.
- Removing the plugin preserves metadata already written to media items and
  collections; it does not roll those changes back.

## Known limitations

- Only direct Movie and Series tags and collection membership participate.
  Episodes, seasons, music, inherited tags, and implicit conversion are out of
  scope.
- V1 does not include a global manual-only mode. Enabled mappings reconcile
  automatically; one-time operations remain available without persisting an
  edge.
- External metadata or collection changes can trigger Authoritative removals.
  Use Additive policy when externally managed target values must be preserved.
- Automated tests cover the UI controller and live server APIs, but visual
  polish and normal-workflow usability remain maintainer alpha-validation work.
- Compatibility has been exercised only against Jellyfin 10.11.11 in the
  isolated Linux test environment.

## Release evidence

The tagged release is built and tested from an exact clean checkout. The
workflow verifies aligned tag/build/assembly/package/manifest versions, inspects
the two-file JPRM ZIP, publishes a SHA-256 companion asset, verifies the uploaded
bytes, and generates the dedicated `manifest` branch with the immutable release
asset URL.

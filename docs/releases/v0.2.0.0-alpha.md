# Collection Tag Sync 0.2.0.0 alpha

This third alpha makes run-once mappings reusable and independently executable,
fixes saved administrator-form hydration, and adds a real-browser regression
gate. Back up the Jellyfin configuration and data directories before upgrading,
and review every destructive preview before confirmation.

## Compatibility

- Jellyfin server: 10.11.11
- Plugin target ABI: 10.11.11.0
- Plugin runtime: .NET 9 (`net9.0`)
- Validated environment: Jellyfin's 10.11.11 Linux container under WSL 2
- Native Windows Jellyfin and older server releases are not claimed compatible

## Included behavior

- Reusable run-once groups persist a target, ordered OR sources, and policy
- Each run-once group has its own compact source-to-target card and explicit
  Edit, Save, Preview, and Delete actions
- Preview and confirmation execute exactly one selected saved group; groups are
  retained after success, failure, or rejection
- Per-item preview exclusions remain execution-only and are never saved into a
  reusable group
- Editing, deleting, or selecting a different group invalidates a prior preview
- Saved Tag/Collection node types and Additive/Authoritative policies reopen
  without being reinterpreted from Jellyfin's string enum representation
- Every canonical all-zero collection GUID format renders as Select a
  collection rather than as a missing collection
- A pinned Docker-backed Playwright suite exercises the packaged plugin through
  Jellyfin's real administrator page and runs in CI after major UI changes

## Installation

Add this third-party repository in the Jellyfin plugin dashboard if it is not
already configured:

```text
https://raw.githubusercontent.com/darvilp/jellyfin-plugin-collection-tag-sync/manifest/manifest.json
```

Upgrade or install Collection Tag Sync 0.2.0.0 from the catalog and restart
Jellyfin when prompted.

## Configuration and upgrade notes

- Configuration schema version remains 1; upgrading initializes an empty saved
  run-once group list without changing continuous mappings.
- Run-once groups are independent of the continuous graph revision and are
  ignored by automatic event, startup, storm, and scheduled reconciliation.
- Saving continuous configuration cannot overwrite saved run-once groups.
- Enabled continuous mappings still reconcile automatically; v1 does not add a
  global manual-only mode.
- Removing the plugin preserves metadata already written to media items and
  collections; it does not roll those changes back.

## Known limitations

- Only direct Movie and Series tags and collection membership participate.
  Episodes, seasons, music, inherited tags, and implicit conversion remain out
  of scope.
- External metadata or collection changes can trigger Authoritative removals.
  Use Additive policy when externally managed target values must be preserved.
- Compatibility has been exercised only against Jellyfin 10.11.11 in the
  isolated Linux test environment.
- Final visual polish remains maintainer alpha validation even though the core
  administrator workflows now have real Chromium coverage.

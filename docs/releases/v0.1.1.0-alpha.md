# Collection Tag Sync 0.1.1.0 alpha

This second alpha focuses on the administrator workflow and on preserving the
intent of explicitly named collections. Back up the Jellyfin configuration and
data directories before upgrading, and review every destructive preview before
confirmation.

## Compatibility

- Jellyfin server: 10.11.11
- Plugin target ABI: 10.11.11.0
- Plugin runtime: .NET 9 (`net9.0`)
- Validated environment: Jellyfin's 10.11.11 Linux container under WSL 2
- Native Windows Jellyfin and older server releases are not claimed compatible

## Included behavior

- Compact continuous mappings summarized as `source OR source → target`, with
  policy, enabled state, and one explicitly editable group at a time
- A distinct global Reconciliation and safety section, with detailed thresholds
  grouped as advanced settings
- A clearer branching Save configuration, Preview changes, and Confirm removals
  and save workflow
- Movie and Series titles in configuration, run-once, and Full Reconcile
  previews, while retaining Jellyfin GUIDs for troubleshooting
- A focused Add new collection modal that returns to its originating picker and
  safely ignores stale asynchronous responses
- Fresh collection pickers default to Select a collection rather than showing
  the all-zero GUID as missing
- Explicitly named plugin-created collections start locked so Jellyfin metadata
  providers cannot replace the requested name

## Installation

Add this third-party repository in the Jellyfin plugin dashboard if it is not
already configured:

```text
https://raw.githubusercontent.com/darvilp/jellyfin-plugin-collection-tag-sync/manifest/manifest.json
```

Upgrade or install Collection Tag Sync 0.1.1.0 from the catalog and restart
Jellyfin when prompted.

## Configuration and upgrade notes

- Configuration schema version remains 1.
- The release workflow installs the published 0.1.0.0 package, writes a sentinel
  configuration through its validated API, upgrades through Jellyfin's catalog,
  restarts, and verifies the same revision, settings, and disabled GUID-backed
  mapping under 0.1.1.0.
- Existing collections are not automatically locked or renamed. Only new
  collections created through Add new collection start locked. Administrators
  may later unlock them in Jellyfin to opt into provider-managed metadata.
- Enabled continuous mappings still reconcile automatically; v1 does not add a
  global manual-only mode.
- Collection creation remains immediate and is not rolled back if a surrounding
  configuration or run-once workflow is canceled or rejected.
- Removing the plugin preserves metadata already written to media items and
  collections; it does not roll those changes back.

## Known limitations

- Only direct Movie and Series tags and collection membership participate.
  Episodes, seasons, music, inherited tags, and implicit conversion remain out
  of scope.
- External metadata or collection changes can trigger Authoritative removals.
  Use Additive policy when externally managed target values must be preserved.
- Automated tests cover the rendered administrator DOM/controller and live
  server APIs; final visual polish remains maintainer alpha validation.
- Compatibility has been exercised only against Jellyfin 10.11.11 in the
  isolated Linux test environment.

## Release evidence

The tagged release is built and tested from an exact clean checkout. The
workflow verifies aligned tag/build/assembly/package/manifest versions, clean
catalog installation, a real public-package upgrade with configuration
retention, the two-file JPRM ZIP, its SHA-256 companion, uploaded byte identity,
and preservation of historical manifest entries.

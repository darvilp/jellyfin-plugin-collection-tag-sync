# Collection Tag Sync 0.3.0.0 alpha, unreleased

## Compatibility

- Jellyfin 12.0.0 minimum build target, target ABI 12.0.0.0.
- .NET 10, net10.0.
- Runtime validation is pending. Do not publish until the
  [migration handoff](../compatibility/jellyfin-12.md) is complete.

## Included behavior

The existing tag and collection synchronization behavior is retained.
Builds, test projects, packaging and the isolated Compose fixture target Jellyfin 12.

## Configuration and upgrade notes

Plugin GUID and configuration schema are unchanged. Keep backups of the server
configuration and data before testing a server upgrade. The old public packages
remain for Jellyfin 10.11. The legacy source is on
[legacy/jellyfin-10.11](https://github.com/darvilp/jellyfin-plugin-collection-tag-sync/tree/legacy/jellyfin-10.11).

There is no public Jellyfin 12 predecessor yet, so `upgradeFrom` is omitted.
The same-server catalog upgrade test cannot prove a cross-ABI server migration.

## Known limitations

No Jellyfin server runtime, browser integration, catalog installation or
cross-ABI configuration retention has been validated for this build yet.
